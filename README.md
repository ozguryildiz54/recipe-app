# Recipe App

🔗 **Live Demo:** https://yldzozgur.github.io/recipe-app/

A React + Vite recipe discovery web app. Browse recipes, view detailed ingredients and instructions, and navigate through a clean responsive UI. Live debounced search, category filtering, dark mode, and gh-pages deployment.

## ✨ Features

- Recipe search and browsing
- Recipe detail pages with ingredients and instructions
- Responsive layout with Tailwind CSS
- Client-side routing with React Router v7
- Global state with React Context

## 🧰 Stack

`React 19` · `Vite` · `Tailwind CSS` · `React Router v7` · `Axios` · `Context API` · `ESLint`

## 🗂 Structure

```
src/
├── components/     # Header, RecipeNavbar
├── context/        # RecipeProvider (global recipe state)
├── pages/          # Home, Details, RecipeCard, About, Layout
├── router/         # App routing
└── App.jsx
```

## 🚀 Run Locally

```bash
npm install
npm run dev
```

App runs at `http://localhost:5173`.
